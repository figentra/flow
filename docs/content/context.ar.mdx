يجيب `fflow context` عن سؤال «أين أنظر؟» لوكيل أو شخص يدخل مستودعًا: التعليمات المحدودة النطاق التي تنطبق على مسار،
ونقاط الدخول، والحزم التي تطابق استعلامًا، من شجرة العمل، بلا تهيئة وبلا شبكة.

```sh
fflow context --json                                     # النسخة الحالية، بلا حاجة إلى سجل
fflow context --path packages/flow --limit 10            # التعليمات المحدودة النطاق والتنقّل
fflow context --repo ../service --query payments --json  # نسخة مستقلة صريحة
fflow context --all --query payments --json              # مساحة عمل fflow المسجَّلة
```

## ما يقرؤه وما يعيده

يقرأ الاكتشاف مسارات git المتتبَّعة وغير المتتبَّعة غير المتجاهَلة، مع أسماء الحزم وأوصافها. ويعيد حتى 20 تطابقًا لكل
مستودع (من 1 إلى 100)، وحتى 25 مستودعًا مسجَّلًا، ورأسَ كل مستودع وفرعه وعلامة اتساخه، ومسارات التعليمات الأعلى (ومنها
`AGENTS.override.md`)، ونقاط الدخول، وبيانات الوصف الناقصة أو غير الصالحة صراحةً. النتائج غير مخبّأة وتصف شجرة
العمل؛ والرأس وحده لا يكفي حين تكون الشجرة متسخة. ضيّق الاستعلام أو اختر مستودعًا واحدًا حين تُبتر النتيجة؛ والنتيجة
المبتورة وحدها ليست فشلًا. المستودعات المفقودة وبيانات الحزم المشوَّهة تخرج بالرمز 1؛ والخيارات غير الصالحة بالرمز 2.

لا يجلب ولا يثبّت ولا يشغّل نصوصًا ولا يحمّل متون الوثائق الخاصة ولا يتبع الروابط الرمزية ولا يجتاز التبعيات أو
مخرجات البناء. تُصنَّف المسارات للتنقّل؛ ولا يُعرض رسمٌ مستنتَج للمالكين أو المستهلكين على أنه حقيقة. الملفات
المتجاهَلة وأسماء ملفات التعليمات المخصَّصة والتعليمات الأعلى خارج النسخة لا تُفهرس: وتبقى تعليمات العميل المنطبقة
هي الحاكمة.

## عبر MCP

يقدّم `fflow mcp` النتيجة نفسها باسم `fflow_context`. مطابقة الاستعلام بالمسار والاسم والوصف، لا بمحتوى الوثائق؛
و`fflow_docs_lookup` هو البحث النثري المحدود. وعند غياب التطابقات استعمل بحث المستودع وبلّغ عن المسار المفقود.

## أين ينتمي الإرشاد

| الحدّ           | أقل إرشاد نافع                                                                                           |
| --------------- | -------------------------------------------------------------------------------------------------------- |
| المستودع        | تنقّل README، وقيود AGENTS المحدودة النطاق، والإرشاد المثبَّت، وبيئة التحقق المسموح بها                  |
| الحزمة، الخدمة  | الغرض والمالك، والصادرات العامة، وواجهة البرمجة والأحداث، والتبعيات، وحدود الفشل، ومثال واحد والاختبارات |
| عائلة المكوّنات | الاستيراد والنوع، والتركيب، وإمكانية الوصول، وسلوك المنصة والحالة المتصل بالمكوّن                        |
| القدرة          | مدخل الفهرس الذي يربط مالكي الخطوات والعقود والمستهلكين والتفويض وسلوك الفشل، ودليل الاختبار             |
| المهارة، الدور  | مُطلِق ضيّق، والمتطلبات وتوافق الإصدارات، والإجراء، والمخرَج، والتحقق ومسار الفشل                        |

أضف الإرشاد عند حدود الملكية أو العقد الحقيقية، لا لكل مجلد أو دالة عادية. يشرح README الاستعمال، ويحكم AGENTS
العمل، ويفسّر ADR قرارًا، ويحدّد العقد السلوك، وتقدّم الاختبارات دليلًا خاصًا بمراجعة بعينها. والطابع الزمني الأحدث
وحده لا ينسخ قرارًا. حدّث المصادر المولِّدة لا الإسقاطات. وعامل حالة الإصدار والنشر على أنها مجهولة حتى يوجد دليل
مطابق؛ ووجود ملفات الاختبار ليس دليلًا على أنها نجحت.
